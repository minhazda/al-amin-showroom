# Al Amin Showroom — phone page

The phone page of the Al Amin Traders showroom book. It holds no data and no secrets: the book is the owner's Google Sheet, and every request needs a phone allowed by the owner and a person's PIN.

Open https://minhazda.github.io/al-amin-showroom/ on the shop phones. The first time, the owner gives a 10-digit code from the Sheet menu (Showroom > Phones: allow a new phone).

Source and tests live in the private repository; this copy is `src/Index.html` from there.
